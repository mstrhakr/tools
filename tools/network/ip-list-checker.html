How matching works

Each reference entry becomes a numeric interval. Sorted intervals allow fast lookups without expanding networks into individual addresses. Overlaps and duplicates are fine; one matching original entry and its reference line are shown.

  • CIDRs: host bits are normalized. 192.168.1.23/24 covers 192.168.1.0 - 192.168.1.255, including network and broadcast addresses.
  • IPv6: compressed and full notation are supported. IPv4 and IPv6 match separately; IPv4-mapped IPv6 remains IPv6. No ports, brackets, or zone IDs.
  • Validation: invalid reference entries block checking unless explicitly skipped. Invalid query IPs get their own result, never “not included.”
  • Limits: 100,000 entries and 5 MiB of characters per list. Results are paginated; copying and CSV export include all corresponding results, not just the visible page.
  • Meaning: inclusion only means membership in your list — not that an IP is safe, malicious, reachable, or currently blocked.

List processing stays local; pasted text and file contents are not sent to a server or stored by this tool. No external IP library or API is required.
